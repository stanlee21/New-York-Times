# New York Times Homepage Clone

A collaborative frontend development project focused on recreating the homepage layout of The New York Times site using HTML5 and CSS3.

## About the Project

This project is a recreation of The New York Times homepage, developed as a team project by two frontend developers.

The goal is to practise frontend development fundamentals, improve our understanding of the site layouts and responsive design, and gain practical experience working collaboratively with Git and GitHub.

Our focus is on recreating the overall homepage structure, including its header, navigation, news sections, featured stories and footer.

**Note:** This is an educational project and is not affiliated with or endorsed by The New York Times.

## Project Objectives

- Practise writing clean and semantic HTML.
- Improve CSS styling and layout skills.
- Understand CSS Flexbox and Grid.
- Learn responsive web design.
- Gain experience with Git and GitHub collaboration.
- Understand feature branches, commits and pull requests.
- Develop teamwork and problem-solving skills.

## Technologies Used

- **HTML5** – For structuring the site.
- **CSS3** – For styling and page layouts.
- **Git** – For version control.
- **GitHub** – For repository hosting and team collaboration.
- **Visual Studio Code** – For code editing.

## Project Features

The homepage will include:

- Website header and branding.
- Navigation menu.
- Featured news stories.
- News headlines and article previews.
- Multiple news sections and categories.
- Images and editorial layouts.
- Footer section.
- Responsive layouts for different screen sizes.

## Collaboration Workflow

We use Git and GitHub to manage our collaborative development process.

Our workflow includes:

1. Clone the project repository.
2. Create a separate feature branch for assigned tasks.
3. Implement and test changes locally.
4. Commit changes with descriptive messages.
5. Push feature branches to GitHub.
6. Open pull requests for code review.
7. Merge approved changes into the main branch.

Direct pushes to the main branch are avoided to maintain an organised collaboration process.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Git
- Visual Studio Code
- A modern web browser

### Installation

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/New_York_Time_Clone.git
```

1. Navigate into the project directory:

```bash
cd New_York_Time_Clone
```

1. Open the project in Visual Studio Code:

```bash
code .
```

1. Open `index.html` in your browser to view the homepage.
